Gatekeeper In progress

A quality gate for AI-drafted lifecycle messages. Synthetic customers move through a made-up SaaS trial. A model drafts onboarding nudges and win-backs, a rubric scores each one on voice, grounding, personalization, compliance, and tone, and the gate routes it to auto-send, human review, or block. The demo runs on precomputed outputs, so it needs no backend or API key.

The question it answers: where do you put the human in the loop for AI-written messages, and how do you measure it?
