How I work

AI is in every step. A person signs off at every step too. Pick a lens.

  1. Discover

    Skills prep each interview guide and score every call the same way.

    I lead the interviews, from a 600+ client panel I stratified by tier, tenure, and engagement.

  2. Sketch

    AI design tools and Claude Code get a working prototype onto real data.

    I'm the team's designer. Every design gets a scored critique before it moves.

  3. Spec

    A spec skill turns interview notes into a first draft I argue with.

    I lock the contested decisions with engineering before the build, not during it.

  4. Data

    Agents help write and sanity-check SQL against production.

    I validate the math against real clients myself before anyone builds on it.

  5. Pull request

    I build UI changes with Claude Code against the QA environment.

    I open the PR; engineers review, merge, and ship under their usual standards.

  6. Ship

    Release and reporting skills draft the notes, guides, and readout.

    I present releases live to 150+ coaches and to cross-functional leadership.

In progress

The toy at the top of this page, grown up. Synthetic customers move through a made-up SaaS trial. A model drafts onboarding nudges and win-backs. A rubric scores each on brand voice, grounding in the customer's data, personalization, compliance, and tone, then routes it to auto-send, human review, or block, with a staged-rollout view by segment.

The demo runs on precomputed outputs, so it needs no backend or API key. The repo will carry the script that regenerates them.
